## STEP-BY-STEP: Upload to GitHub (First Time Users)

### 1️⃣ Create GitHub Account (2 minutes)
- Go to: https://github.com/signup
- Enter email, create password
- Verify your email

### 2️⃣ Create Repository (1 minute)
- Click "+" in top right → "New repository"
- Name: `ramya-tiles-website`
- Make it "Public"
- Click "Create repository"

### 3️⃣ Upload Files (2 minutes)
- Click "uploading an existing file"
- Drag these 5 files:
  * index.html
  * styles.css
  * script.js
  * README.md
  * .gitignore
- Click "Commit changes"

### 4️⃣ Enable Free Hosting (2 minutes)
- Go to "Settings" tab in your repository
- Click "Pages" in left menu
- Under "Source", select "main" branch
- Click "Save"
- Wait 2-3 minutes

### 5️⃣ Your Website is LIVE! 🎉
Your website will be at:
```
https://YOUR-USERNAME.github.io/ramya-tiles-website/
```

## Connect Your .in Domain (After Site is Live)

### For RamyaTilesworkcontractor.in:

1. In your repository, click "Add file" → "Create new file"
2. Name it: `CNAME` (all caps)
3. Content (one line): `RamyaTilesworkcontractor.in`
4. Click "Commit"

5. Go to your domain registrar (where you bought the domain)
6. Find DNS settings
7. Add these records:
   ```
   Type: A     | Host: @   | Value: 185.199.108.153
   Type: A     | Host: @   | Value: 185.199.109.153
   Type: A     | Host: @   | Value: 185.199.110.153
   Type: A     | Host: @   | Value: 185.199.111.153
   Type: CNAME | Host: www | Value: YOUR-USERNAME.github.io
   ```

8. Wait 24-48 hours for DNS to propagate

## Alternative: Use Netlify (Easier Domain Setup)

### Why Netlify?
- Easier to connect custom domain
- Free SSL certificate
- Better performance
- Simpler setup

### Steps:
1. Go to: https://netlify.com
2. Sign up with GitHub
3. Click "Add new site" → "Import from Git"
4. Choose your repository
5. Click "Deploy"
6. Go to "Domain settings" → "Add custom domain"
7. Enter: RamyaTilesworkcontractor.in
8. Follow their DNS instructions

## Common Issues & Solutions

**Problem:** Website not loading after 10 minutes
**Solution:** Check if GitHub Pages is enabled in Settings → Pages

**Problem:** Forms not working
**Solution:** Make sure you updated the phone/email in index.html

**Problem:** WhatsApp opens but wrong number
**Solution:** Update the WhatsApp link in index.html (find "wa.me")

**Problem:** Domain not connecting
**Solution:** DNS takes 24-48 hours. Be patient. Check DNS records are correct.
