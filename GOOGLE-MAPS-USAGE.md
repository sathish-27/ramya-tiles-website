## 🆘 Troubleshooting

**Map not showing?**
- Check internet connection
- Clear browser cache
- Try different browser

**Wrong location on map?**
- Coordinates are: 13.0494914, 80.1636755
- These match your Google Business Profile
- If wrong, update in the iframe src

**Buttons not working?**
- Check phone number format
- Verify WhatsApp number
- Test on different devices
