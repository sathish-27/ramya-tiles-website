# 🏠 Ramya Tiles Work Contractor Website (Angular 19 + Vercel)

A modern, high-performance **Angular web application** for **Ramya Tiles Work Contractor**, highlighting **25+ years of master craftsmanship**, precision tile laying, complete bathroom renovations, alteration works, terrace cooling tiles, and epoxy grouting across Chennai, Tamil Nadu.

---

## ✨ Key Features

- **🏆 25+ Years Experience Showcase**:
  - Highlights master craftsman expertise, perfect surface leveling, zero hollow sound guarantee, and precision water drainage slopes.
  - Direct Contractor pricing (no broker or middleman commissions).
- **🛠️ Comprehensive Service Spectrum**:
  - New Floor Tiling (Vitrified, Ceramic, Granite, Marble, Large Format 2x4 & 4x6 slabs)
  - Complete Bathroom Renovation & Remodeling with 2-layer waterproofing
  - Kitchen & Backsplash Modernization
  - Alterations, Demolition & Safe Debris Removal
  - Hollow & Cracked Tile Repair (without damaging adjacent tiles)
  - Terrace Solar Cooling Weathering Tiles (cuts room heat by 4°C - 7°C)
  - Parking & Heavy-Duty Pavers
  - 100% Waterproof & Stain-Proof Epoxy Grouting
- **🧮 Interactive Tile Cost & Area Calculator**:
  - Dynamic area slider (50 to 3,000 sq.ft) with quick room presets.
  - Labor Only vs Labor + Mortar/Adhesive materials selection.
  - Optional add-ons (Demolition, Waterproofing, Epoxy grout).
  - Instant itemized cost breakdown and project duration estimates.
  - **"Send Estimate to WhatsApp"** button: pre-formats all calculations directly into a WhatsApp message to the contractor!
- **📸 Filterable Project Portfolio**:
  - Living rooms, Bathrooms, Kitchens, Terraces, Commercial parking with project specifications and locations in Chennai.
- **📱 One-Tap WhatsApp & Phone Connect**:
  - Click-to-call, direct WhatsApp chat, floating conversion button, and site visit request form.
- **⚡ Vercel Cloud Ready**:
  - Pre-configured `vercel.json` with SPA route rewrites and automatic build optimization.

## 💻 Local Development

```bash
# Install dependencies (already installed)
npm install

# Start local development server
npm start
```
Open your browser and navigate to `http://localhost:4200`.

---

## 🚀 Build & Deploy to Vercel

```bash
# Run production build
npm run build
```
Built output files will be in `dist/ramya-tiles-app/browser`.
